# Google Play 스토어 등록 문구

## 기본 정보

- 기본 언어: 한국어(대한민국)
- 앱 이름: `한 달 일정 보내기`
- 앱 또는 게임: 앱
- 가격: 무료
- 카테고리: 생산성
- 앱 패키지: `io.github.pro047.calendarexporter`
- 웹사이트: `https://pro047.github.io/calenderexporter/`
- 개인정보처리방침: `https://pro047.github.io/calenderexporter/privacy.html`
- 지원 페이지: `https://github.com/pro047/calenderexporter/issues/new`
- 지원 이메일: Play Console 계정에서 실제로 확인하는 이메일을 입력한다.

## 간단한 설명

```text
휴대폰의 한 달 일정을 불러와 카톡·문자 또는 텍스트 파일로 보내세요.
```

## 자세한 설명

```text
한 달 일정 보내기는 휴대폰에 저장된 일정을 월별로 정리해 보내는 앱입니다.

원하는 달과 일정표를 고른 뒤 일정을 불러오세요. 확인한 내용은 카카오톡이나 문자 메시지의 본문으로 바로 보내거나, 텍스트 파일로 전달할 수 있습니다.

주요 기능
• 이전 달과 다음 달 선택
• 여러 일정표 중 가져올 일정표 선택
• 반복 일정과 종일 일정 표시
• 일정 제목, 시간, 장소를 읽기 쉬운 목록으로 정리
• 카카오톡·문자 등으로 일반 텍스트 공유
• TXT 파일 공유

개인정보 보호
• 일정 읽기 권한만 사용합니다.
• 기존 일정을 만들거나 수정하거나 삭제하지 않습니다.
• 일정은 휴대폰 안에서 처리됩니다.
• 자체 서버, 광고 또는 분석 서비스를 사용하지 않습니다.
• 로그인과 회원가입이 필요 없습니다.

공유 버튼을 누른 뒤 보낼 앱과 사람은 사용자가 직접 선택합니다.
```

## 내부 테스트 출시 노트

```text
0.1.3 내부 테스트
• 일정을 불러오는 중에도 이전 달과 다음 달 선택 가능
• 달을 바꾼 뒤 이전 달 결과가 표시되지 않도록 개선
• 느린 캘린더 기기에서 달 선택 반응 개선
```
