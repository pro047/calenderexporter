# 한 달 일정 보내기 0.1.2

일정을 고르고 보내는 흐름을 더 크고 단순하게 다듬은 버전입니다.

## 변경 사항

- Apple의 그룹형 화면에서 착안한 밝고 절제된 디자인 적용
- 큰 제목과 16sp 이상 본문, 56dp 이상 공유 버튼으로 가독성 개선
- 일정표 선택을 가로 스크롤에서 세로 목록으로 변경
- 메시지·카카오톡 공유를 첫 번째 파란 주 버튼으로 강조
- 버튼 문구를 `카톡·문자로 보내기`, `파일로 보내기`로 단순화
- 미리보기 안내와 로딩·오류 상태의 시각적 위계 개선

## 보안과 개인정보

- 일정 읽기 권한만 사용
- 일정 수정 권한과 인터넷 권한 없음
- 0.1.1과 같은 서명 키를 사용하므로 기존 앱 위에 업데이트 가능
