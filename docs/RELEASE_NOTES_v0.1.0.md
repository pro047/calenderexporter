# 한 달 일정 파일 만들기 0.1.0

첫 공개 시험 버전입니다.

## 주요 기능

- 휴대폰 일정표와 대상 월 선택
- 한 달의 일반·종일·반복·여러 날 일정 불러오기
- 일정 미리보기
- 표 파일(CSV), 자료 파일(JSON), 글 파일(TXT) 보내기
- 일정 읽기 전용 동작

## 확인 사항

- Samsung SM-A716S, Android 13에서 새 설치와 덮어쓰기 설치 확인
- 2026년 8월 원래 일정 6개 조회 확인
- 별도 시험 일정 128개 조회와 세 파일 생성 확인
- 일정 읽기 권한만 포함
- 일정 수정 권한과 인터넷 권한 없음
