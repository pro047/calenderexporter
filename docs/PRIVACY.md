# 개인정보 및 Data Safety 초안

## 데이터 처리 원칙

- 앱은 `READ_CALENDAR`만 요청하며 일정을 생성·수정·삭제하지 않는다.
- 캘린더 조회와 포맷 변환은 기기 안에서 수행한다.
- 앱 자체 서버나 분석 서비스로 캘린더 데이터를 전송하지 않는다.
- 사용자가 `파일로 보내기`를 누를 때만 선택한 월의 파일을 앱 캐시에 생성한다.
- `카톡·문자로 보내기`는 파일을 만들지 않고 선택한 월의 내용을 공유 대상으로 전달한다.
- 공유 대상은 Android 시스템 공유 시트에서 사용자가 직접 선택한다.
- 캐시 파일은 앱 삭제 또는 시스템의 캐시 정리 대상이다.

## Play Console 점검 항목

- Data Safety의 Calendar 데이터 접근을 선언한다.
- 데이터가 기기 밖으로 전송되지 않는 현재 구현을 기준으로 수집 여부를 판단한다.
- 향후 분석 SDK, 클라우드 업로드 또는 계정 기능을 추가하면 선언을 다시 검토한다.
- 권한 요청 직전에 기능상 이유를 설명하고 거부해도 앱이 종료되지 않도록 한다.

이 문서는 개발 초안이며 출시 전 실제 배포 빌드의 SDK와 네트워크 동작을 기준으로 최종 검토해야 한다.
