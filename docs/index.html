    앱을 열고 일정 읽기를 허용합니다.

다운로드나 설치가 안 되나요?
  1. 0.1.0이 설치되어 있으면 기존 앱을 먼저 삭제하세요. 휴대폰의 원래 일정은 삭제되지 않습니다. 0.1.1은 삭제하지 않고 업데이트할 수 있습니다.
  2. 카카오톡에서 다운로드가 시작되지 않으면 오른쪽 위 메뉴에서 다른 브라우저로 열기를 선택하세요.
  3. 설치 차단 화면에 나온 설정을 눌러 다운로드에 사용한 앱의 이 출처 허용을 켜세요.
  4. Play 프로텍트가 확인을 요구하면 파일 이름과 이 페이지의 주소를 확인한 뒤 화면의 추가 설치 선택지를 사용하세요.
  5. 그래도 막히는 삼성 휴대폰에서만 설정 → 보안 및 개인정보 보호 → 자동 차단을 설치할 때 잠시 끄세요.
  6. 설치가 끝나면 바꾼 보안 설정을 원래대로 되돌리세요.

꼭 확인하세요.자동 차단 해제는 다른 방법으로 설치되지 않을 때만 사용하고, 설치가 끝나면 반드시 다시 켜세요.
