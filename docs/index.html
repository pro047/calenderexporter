앱 다운로드하기

안드로이드 8 이상 휴대폰용 · 약 1.8MB

안심하고 사용하세요

  • 일정을 읽기만 하고 바꾸거나 지우지 않습니다.
  • 앱이 일정을 자동으로 인터넷에 보내지 않습니다.
  • 필요한 파일은 휴대폰 안에서 만듭니다.
  • 파일을 보낼 앱과 사람은 직접 선택합니다.

설치는 3단계면 됩니다

  1. 다운로드 버튼을 누르세요.위의 초록색 버튼을 누릅니다.
  2. 받은 파일을 설치하세요.다운로드한 파일을 열고 설치를 누릅니다.
  3. 일정 읽기를 허용하세요.앱을 열고 일정 읽기 허용을 누릅니다.
설치가 안 될 때 보기
  1. 다운로드가 시작되지 않으면 카카오톡 오른쪽 위 메뉴에서 다른 브라우저로 열기를 선택하세요.
  2. 설치 차단 화면에 나온 설정을 누르세요.
  3. 다운로드에 사용한 인터넷 앱의 이 출처 허용을 켜세요.
  4. 그래도 막히는 삼성 휴대폰에서만 설정 → 보안 및 개인정보 보호 → 자동 차단을 설치할 때 잠시 끄세요.
  5. 설치가 끝나면 바꾼 보안 설정을 원래대로 되돌리세요.

휴대폰 모델과 안드로이드 버전에 따라 설정 이름이 조금 다를 수 있습니다.

꼭 확인하세요.자동 차단 해제는 다른 방법으로 설치되지 않을 때만 사용하고, 설치가 끝나면 반드시 다시 켜세요.

내 일정은 어떻게 처리되나요?
