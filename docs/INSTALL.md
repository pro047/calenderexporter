# 설치 안내

## 처음 설치할 때

1. GitHub Release에서 `month-calendar-exporter-v0.1.0.apk`를 내려받습니다.
2. 다운로드가 끝나면 파일을 누릅니다.
3. 설치가 차단되면 화면 안내에 따라 다운로드에 사용한 브라우저 또는 파일 앱의
   `출처를 알 수 없는 앱 설치`를 허용합니다.
4. 삼성 휴대폰에서 계속 차단되면 `설정 → 보안 및 개인정보 보호 → 자동 차단`을
   확인하고 설치하는 동안만 해제합니다.
5. 앱 설치가 끝나면 자동 차단을 다시 켭니다.
6. 앱을 열고 `일정 읽기 허용`을 누른 뒤 휴대폰의 권한 안내를 승인합니다.

설정 이름은 휴대폰 모델과 Android 버전에 따라 조금 다를 수 있습니다.

## 새 버전으로 바꿀 때

기존 앱을 삭제하지 말고 새 APK를 내려받아 그대로 설치합니다. 같은 배포용 도장으로
만든 새 버전이면 기존 앱 위에 설치되며 일정 읽기 허용 상태도 유지됩니다.

## 파일이 맞는지 확인할 때

버전 0.1.0 APK의 SHA-256 확인값은 다음과 같습니다.

```text
527C3378EEA332C44531070AD24E2FC437D4B0251EBD69CE8402E2A699390E12
```

앱은 일정 읽기 권한만 요청하며 일정 수정 권한과 인터넷 권한은 사용하지 않습니다.
