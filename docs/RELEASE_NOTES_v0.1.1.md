# 한 달 일정 파일 만들기 0.1.1

메시지와 카카오톡 공유를 쉽게 만든 버전입니다.

## 변경 사항

- CSV와 JSON 내보내기 제거
- `텍스트 파일로 내보내기` 추가
- 파일 첨부 없이 메시지 본문을 보내는 `텍스트로 내보내기` 추가
- 날짜와 시간을 읽기 쉬운 한국어 형식으로 변경
- 하루 종일 일정의 종료일을 실제 포함 날짜로 표시
- 새 배포용 서명 키 적용: 0.1.0 사용자는 기존 앱 삭제 후 설치 필요

## 보안과 개인정보

- 일정 읽기 권한만 사용
- 일정 수정 권한과 인터넷 권한 없음
- 텍스트 파일은 공유 버튼을 누를 때 휴대폰 캐시에만 생성
