| 월 경계 일정 | 1 | 1 | 1 |
| 매주 반복 일정 | 1 | 5 | 5 |
| 일반 일정 | 1 | 1 | 1 |
| 종일 일정 | 1 | 1 | 1 |
| 합계 | 4 | 8 | 8 |

추가 확인:

- `READ_CALENDAR` 권한 부여 후 앱 콜드 스타트 성공
- 캘린더 선택 기본값과 월간 미리보기 정상
- 기기 시간대가 UTC일 때 7건, `Asia/Seoul`일 때 월 경계 포함 8건으로 반개방 범위가 예상대로 동작
- CSV 공유 시트에서 `calendar-2026-08.csv` 1개 파일 표시
- CSV 파일은 UTF-8 BOM, 8개 데이터 행, 종일 종료일 제외 표현을 포함
- 앱 충돌 없음. 기록된 프로세스 종료는 APK 업데이트로 인한 정상 종료뿐
- 테스트 후 임시 캘린더와 종속 이벤트 삭제 확인
- 최종 target SDK 36 APK를 데이터가 없는 상태로 제거 후 재설치
- 최초 기능 버튼을 누르기 전에는 권한 창이 나타나지 않고, 버튼을 누른 시점에 시스템 `READ_CALENDAR` 창 표시

### 실기기 다량 일정 검증

검증일: 2026-08-24

개인 일정표와 분리된 임시 로컬 일정표를 만든 뒤, 2026년 8월에
일반·종일·여러 날·매주 반복·월 경계 가짜 일정을 넣었다. 초기 입력 재시도분
6개를 포함해 앱 화면에서 총 128개를 불러왔다.

- 테스트 일정표 하나만 선택된 상태 확인
- `2026년 8월 · 일정 128개` 표시 및 미리보기 생성 확인
- 기기 조작과 화면 확인 시간을 포함해 약 5초 안에 결과 화면 확인
- 보내기 화면에서 `calendar-2026-08.csv`, `.json`, `.txt` 파일명 확인
- 생성 파일 크기: CSV 17,148바이트, JSON 38,452바이트, TXT 14,408바이트
- 공유 대상을 선택하지 않아 외부 앱으로 전송되지 않음
- 시험 후 테스트 일정표를 삭제해 해당 8월 일정이 0개임을 확인
- 원래 8월 일정은 시험 전과 같은 6개로 유지됨을 확인
- 앱의 세 임시 파일과 기기에 올린 입력 스크립트 삭제 확인

추가 기기에서 확인할 때는 다음 항목을 사용한다.

실제 Google·삼성·Exchange 동기화 환경에서는 다음을 확인한다.

- 캘린더 이름과 표시 여부
- 반복 일정 및 수정·취소된 단일 회차
- 공휴일·생일 캘린더 선택 해제
- 여러 날 일정과 월 경계
- 종일 일정의 날짜
- CSV를 Excel 또는 Google Sheets에서 열었을 때 한글과 열 구분
- 권한 거부, 영구 거부, 설정에서 재허용

실기기에서 다량 시험을 할 때는 개인 일정표가 아닌 별도의 로컬 테스트 일정표만
만들고, 시험 후 그 일정표의 식별자를 확인해 일정표 전체를 삭제한다.
