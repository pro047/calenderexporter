개인정보처리방침

시행일: 2026년 8월 24일

일정 내용은 휴대폰 안에서만 처리됩니다. 개발자는 사용자의 일정을 수집하거나 열람할 수 없습니다.

처리하는 정보

사용자가 일정 읽기를 허용하면 일정 제목, 시작·종료 시각, 종일 일정 여부, 장소와 캘린더 이름을 기기 안에서 처리합니다.

연락처, 사진, 위치, 광고 식별자 또는 계정 비밀번호에는 접근하지 않습니다.

이용 목적

일정 정보는 사용자가 선택한 달의 일정을 화면에 표시하고, 메시지 본문 또는 텍스트 파일로 정리하는 데에만 사용됩니다.

저장과 외부 전송

  • 일정 조회와 텍스트 변환은 사용자의 기기 안에서 이루어집니다.
  • 앱은 인터넷 권한을 사용하지 않으며 자체 서버, 광고 또는 분석 서비스를 사용하지 않습니다.
  • 공유 버튼을 누르면 Android 공유 화면이 열리고 사용자가 직접 보낼 앱과 대상을 선택합니다.
  • 파일로 보낼 때 생성되는 임시 파일은 앱 캐시에 저장되며, 캐시 정리 또는 앱 삭제 시 제거될 수 있습니다.

사용자가 선택한 다른 앱에서의 정보 처리는 해당 앱의 개인정보처리방침을 따릅니다.

일정 읽기 권한

앱은 READ_CALENDAR 권한만 요청합니다. 기존 일정을 만들거나 바꾸거나 삭제하는 권한은 요청하지 않습니다.

어린이 개인정보

앱은 어린이를 대상으로 개인정보를 수집하거나 광고를 제공하지 않습니다.

방침 변경

앱의 기능이나 데이터 처리 방식이 바뀌면 이 문서의 시행일과 내용을 갱신합니다.
