# 페이지 전달 자료

## 카카오톡 안내 문구

아래 주소에서 `한 달 일정 보내기` 앱을 받을 수 있어요.
파란색 `앱 다운로드` 버튼을 누른 뒤 화면 안내를 따라 설치해 주세요.

https://pro047.github.io/calenderexporter/

## QR코드

![다운로드 페이지 QR코드](assets/download-page-qr.svg)

QR코드와 카카오톡 안내는 앱 버전이 바뀌어도 위의 같은 페이지 주소를 사용한다.

## 설치 지원 연락처

설치 지원 연락처는 페이지를 전달하는 사람이 카카오톡 메시지에 함께 적는다.
개인 연락처가 공개 웹페이지에 노출되지 않도록 페이지 자체에는 넣지 않는다.
